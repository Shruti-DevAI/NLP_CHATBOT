# NLP_CHATBOT
A simple and intelligent chatbot built using Natural Language Processing (NLP) in Python.## Features

- Intent-based conversation system
- Pattern matching using NLTK
- Responsive and interactive chatbot
- Easy to extend with new intents

## Technologies Used

- Python
- NLTK (Natural Language Toolkit)
- JSON for intent handling
- Google Colab

## How to Run

1. Open the notebook in Google Colab
2. Run all cells
3. Start chatting with the bot!
